## 📌 Project Overview
**TECH FOR EDU** is an interactive web-based resource hub designed to bridge the educational resource gap for G.C.E. Advanced Level Technology stream students in Sri Lanka[cite: 2]. The platform centralizes study materials, including Short Notes, Past Papers, and Model Papers, allowing students and educators to seamlessly browse, search, and share resources[cite: 2].

* **Course:** ICT 1209 - Web Technologies
* **University:** Rajarata University of Sri Lanka (Department of ICT)
* **Batch:** 2024 (First Year, BICT)[cite: 1, 2]

## 🛠️ Technology Stack
Aligned with the official ICT 1209 course guidelines:

---

## 🌟 Key Features (Phase 2 Implementation)

### 1. **Responsive Multi-Page Structure**
* **Home Page (`homepage.html`):** Features a clean navigation bar, hero section, and interactive image slider[cite: 1, 2].
* **Features / Notes Page (`featurepage.html`):** Includes dynamic category filtering options (ET, BST, SFT, ICT, Agri, Home Science) and resource cards[cite: 2].
* **Contact Us Page (`contactpage.html`):** User query form and direct contact details[cite: 2].

### 2. **Interactive JavaScript Features**
* **Auto Image Slider:** Pure CSS & JS powered smooth transition carousel showcasing learning resources on the homepage[cite: 1].
* **Dynamic Search & Filtering:** Instant client-side filtering for subjects and resource types[cite: 2].
* **Interactive Navigation & UI Controls:** Active page state highlighting, interactive dropdowns, and responsive sidebar navigation[cite: 1].
